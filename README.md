# Washoo Landing Page

A modern landing page built with HTML, CSS, JavaScript, jQuery and Swiper.js.

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- jQuery
- Swiper.js
- Font Awesome
- Google Fonts (Montserrat)

## Functionality

### Fixed Header

The navigation bar becomes fixed after scrolling past half of the hero section.

### Hidden Menu

The side menu slides in from the right and can be closed using the close button.

### Scroll To Top

The button in the footer smoothly scrolls the page back to the top.

### Image Slider

The project uses Swiper.js to display images with navigation arrows and infinite looping.

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/washoo-landing-page.git
```

Open the project folder and run `index.html` or use Live Server.
